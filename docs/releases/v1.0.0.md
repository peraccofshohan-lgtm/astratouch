# AstraTouch v1.0.0 — "Your Phone. Your Control."

The first public release of AstraTouch: a floating bubble, radial menu and macro
engine for Android 10–16, built offline and open source under the MIT licence.

## Highlights

### One bubble, everything within reach
A draggable bubble that snaps to any edge, auto-hides, dims while the menu is
open and remembers its position per profile. Seven shapes, gradient fills,
border, shadow, opacity, icon size and haptic feedback are all configurable.

### Radial command center
Eight layouts (full circle, semi circle, quarter circle, grid, compact, expanded,
nested, paged), unlimited slots across pages, custom labels and icons per slot,
favourites and recently used actions.

### 50+ system actions in six categories
Navigation, device, capture, app, productivity and AstraTouch shortcuts. Every
action declares what access it needs and *why* it could not run — you never get a
tap that silently does nothing.

### Macros that survive failure
Sequence actions, delays and conditions; set a timeout; see a per-run history with
the exact failing step. Six ready-made macros ship with the app: Work Mode,
Reading Mode, Gaming Mode, Media Mode, Quick Screenshot and Productivity Mode.

### Profiles that actually isolate
Five purpose-built profiles plus unlimited custom ones. Each owns its own bubble,
radial menu, gestures, theme and macros. One is active at a time, and a profile can
auto-switch on a chosen package.

### Capture, annotate, record
Screenshot through accessibility, crop and annotate in place, share via
FileProvider; screen recording through MediaProjection with a visible notification.

### Productivity built in
Local clipboard history with a sensitive-content filter that refuses OTPs,
passwords and card numbers; quick notes; a real calculator; timers; an app launcher
with favourites and groups.

## Privacy

- **No INTERNET permission.** Not "we don't send your data" — the app *cannot*.
- No analytics, advertising SDK, account or telemetry.
- `allowBackup=false` with data-extraction rules excluding databases and files.
- Accessibility is used only for global actions and screenshots —
  `canRetrieveWindowContent="false"`, so no screen content is ever read.
- Full local export/import and one-tap deletion in Privacy Center.

## Compatibility

Android 10 (API 29) through Android 16 (API 36). Verified on emulators running
API 29, 33 and 36.

## Install

1. Download `AstraTouch-v1.0.0.apk` below.
2. Verify it: `sha256sum -c SHA256SUMS.txt`.
3. Install, then grant *Display over other apps* and enable the accessibility
   service when onboarding asks.

## Known limitations (read this)

- AstraTouch **cannot** intercept gestures on other apps. Android has no API for
  that, and the workaround (an invisible full-screen overlay fishing for input)
  breaks other apps and is rejected here on principle.
- Clipboard history is captured only while AstraTouch has focus — an Android 10+
  restriction.
- Screenshots need Android 11+ via accessibility; Android 10 falls back to
  MediaProjection, which asks for consent each time.
- True blur requires Android 12+; earlier versions get a translucent gradient.
- On-screen text recognition (OCR) is not shipped and its switch is visibly
  disabled rather than faked.
- No cloud sync, by design.

Full detail: [docs/KNOWN_LIMITATIONS.md](https://github.com/peraccofshohan-lgtm/astratouch/blob/main/docs/KNOWN_LIMITATIONS.md).

## Verification

Every release is built by GitHub Actions with gates that abort the publication
unless: the tag matches `versionName` and `versionCode`; unit tests and
`lintRelease` pass; the APK is signed by the release key (not a debug key) with
v2+v3 schemes; the badging reports `com.astratouch.app`, `1.0.0`, `10000`,
minSdk 29 and targetSdk 36; and the published asset's SHA-256 re-verifies after
upload.
