# AstraTouch v1.0.2 — personal debug build

The first **installable** AstraTouch release.

v1.0.0 and v1.0.1 were tagged but never published: both stopped at a signing gate
that demanded a production keystore and four GitHub secrets. For a personal-use
application that was the wrong requirement, and it is now gone.

## What you get

A real, signed, installable APK:

- Signed with a **stable personal-use debug identity** — not an unsigned artifact.
- The same signing certificate as every future build, so **v1.0.3 will install over
  v1.0.2 as an update**, keeping your data.
- Minified and non-debuggable (it is not a raw development build).
- `com.astratouch.app`, minSdk 29, targetSdk 36.

## What changed since v1.0.1

Everything in v1.0.1 — the nine review-driven fixes — plus the signing work:

- Deterministic debug keystore generation with a committed public certificate.
- New `debugPersonal` build type: R8, resource shrinking, real application id.
- v1 and v2 signature schemes both enabled.
- Release pipeline no longer reads any signing secret.
- Release gate re-downloads the published APK and re-verifies its checksum.

See [`CHANGELOG.md`](../../CHANGELOG.md) for the full list.

## Install

1. Download `AstraTouch-v1.0.2-personal-debug.apk` below.
2. Verify the checksum against `SHA256SUMS.txt` (see below).
3. Open the file on your device and allow installation from that source when
   prompted.
4. Grant **Display over other apps** and enable the AstraTouch **accessibility
   service** on first run. Most gesture and automation features need both.
5. Some actions additionally need **write settings** (brightness) — the app asks
   when you first use them.

Full instructions: [`docs/INSTALLATION.md`](../INSTALLATION.md).

## Verify the download

```bash
sha256sum -c SHA256SUMS.txt
```

Expected values are in `SHA256SUMS.txt` and repeated in `release-metadata.json`,
including the signing certificate fingerprint:

```
198476e1822fb79f6c85c426c5c450c66c87db2982b88f90139c1eae19b3920e
```

You can confirm the signer yourself:

```bash
keytool -printcert -jarfile AstraTouch-v1.0.2-personal-debug.apk
```

## Honest limitations

- **This is a debug-signed build.** It is cryptographically valid and
  update-compatible, but it is not a store-quality trust anchor. Google Play would
  reject it.
- **The keystore password is public.** `astratouchdebug` is in the repository. The
  key is derived, not stored, so the password protects nothing — by design.
- **Android may warn** about installing from an unknown source, and Play Protect
  may flag a debug-signed APK. Expected.
- **Not tested on a physical device by the project itself.** See
  [`docs/DEVICE_TESTING.md`](../DEVICE_TESTING.md) for the manual pass; CI proves the
  build, the tests, and the signature, not the touch ergonomics.
